# PMP Certification Quizzes

Interactive quiz applications for PMP (Project Management Professional) certification exam preparation.

## Overview

This repository contains a collection of browser-based quiz applications designed to help users prepare for the PMP certification exam. Each quiz focuses on a specific topic area from the PMBOK Guide and PMI's exam content outline.

Available quizzes include:
- **EVM Quiz** - Earned Value Management calculations and concepts
- **PMP 12 Principles** - The 12 principles of project management
- **PMP 49 Processes** - All 49 processes from the PMBOK Guide
- **Agile Ceremonies** - Agile events and ceremonies
- **PMP Mindset** - PMI's mindset and values
- **Project Documents** - Key project management documents
- **Risk Responses** - Risk response strategies
- **Performance Domains** - The 8 performance domains

## Who This Is For

These quizzes are intended for:
- Individuals preparing for the PMP certification exam
- Project management professionals seeking to reinforce their knowledge
- Anyone studying PMI's PMBOK Guide and exam content

## How to Access the Quizzes

Access the quizzes directly through GitHub Pages:

**https://ugl13rth4nu.github.io/PMP-Certification-Quizzes/**

No installation or setup is required. Simply open the link in your web browser and select the quiz you want to take.

## Technical Notes

All quizzes are implemented as client-side applications using HTML, CSS, and JavaScript. They run entirely in your browser with no server-side components or external dependencies. Each quiz is self-contained in a single HTML file.

The quizzes work on modern web browsers (Chrome, Firefox, Safari, Edge) and are responsive for both desktop and mobile devices.
