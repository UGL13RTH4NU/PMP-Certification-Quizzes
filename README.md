# PMP Certification Quizzes

Interactive study quizzes for PMP (Project Management Professional) certification exam preparation.

## Overview

This repository contains a collection of client-side web applications designed to help you practice and reinforce key concepts for the PMP certification exam. The quizzes cover:

- **EVM (Earned Value Management)** - Practice calculations and formulas
- **PMP 12 Principles** - Learn the fundamental principles
- **PMP 49 Processes** - Master the process groups and knowledge areas
- **Agile Ceremonies** - Understand Agile events and practices
- **PMP Mindset** - Develop the PMI mindset and approach
- **Project Documents** - Identify and understand key project artifacts
- **Risk Responses** - Practice risk response strategies
- **Performance Domains** - Study the eight performance domains

Each quiz provides immediate feedback and explanations to support your learning.

## Who This Is For

These quizzes are for:

- Professionals studying for the PMP certification exam
- Project managers refreshing their knowledge of PMI standards
- Anyone wanting to practice PMP concepts in an interactive format

## Technical Notes

All quizzes are client-side only applications built with HTML, CSS, and JavaScript. They run entirely in your browser with no server-side processing or data collection. No personal information is stored or transmitted.
