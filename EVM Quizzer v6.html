📚 EVM Formula Reference

Given Values (Measured)
BACBudget at Completion - Total project budget. The value of total planned work, the project cost baseline.
PVPlanned Value - Budget for work scheduled (from baseline)(planned % complete × BAC). The value of the work planned to be completed to a point in time, usually the data date, or project completion.
EVEarned Value - Budget for work completed (actual % complete × BAC). The planned value of all the work completed (earned) to a point in time, usually the data date, without reference to actual costs.
ACActual Cost - Money actually spent (sum of the cost for the given period). The actual cost of all the work completed to a point in time, usually the data date.
Variance Formulas
CVCost Variance = EV − AC
SVSchedule Variance = EV − PV
Positive = Good (under budget/ahead)
Negative = Bad (over budget/behind)
Performance Indexes
CPICost Performance Index = EV ÷ AC
SPISchedule Performance Index = EV ÷ PV
> 1.0 = Good (efficient/ahead)
= 1.0 = On track
< 1.0 = Bad (inefficient/behind)
Forecasting Formulas
EACEstimate at Completion = BAC ÷ CPI
(Most common - assumes past performance continues)
ETCEstimate to Complete = EAC − AC
VACVariance at Completion = BAC − EAC
TCPITo-Complete Perf. Index = (BAC − EV) ÷ (BAC − AC)
🔥 Quick Interpretation
CPI = 1.15: Getting $1.15 value per $1 spent ✓
CPI = 0.85: Getting $0.85 value per $1 spent ✗
SPI = 1.20: 20% ahead of schedule ✓
SPI = 0.80: 20% behind schedule ✗
CV = $5,000: $5K under budget ✓
CV = -$5,000: $5K over budget ✗
SV = $10,000: $10K ahead ✓
SV = -$10,000: $10K behind ✗
TCPI > 1.0: Need better efficiency to meet budget
TCPI < 1.0: Can be less efficient and still meet budget
